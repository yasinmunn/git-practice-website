# Git Practice Website

A small HTML, CSS, and JavaScript project for the **Fundamentals of Source Code Versioning** course.

## How to run
Open `index.html` in any web browser. No packages or build tools are needed.

## Learning goals
- Initialize a local repository.
- Record changes using commits.
- Push to a public GitHub repository.
- Create and merge a feature branch.
- Resolve a merge conflict.
